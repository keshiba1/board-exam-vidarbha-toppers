# Vidarbha Board Exam Toppers 2026

Toppers lists for Maharashtra State Board and CBSE board exams — students from Nagpur and the Vidarbha region.

**Live at:** https://vidarbha-board-exam-toppers.duckdns.org

## Pages

| File | Description |
|------|-------------|
| `index.html` | Landing page — links to all exam result pages |
| `hsc.html` | Maharashtra HSC (Class XII) toppers — Science, Commerce, Arts |
| `ssc.html` | Maharashtra SSC (Class X) toppers *(coming soon)* |
| `cbse12.html` | CBSE Class XII toppers *(coming soon)* |
| `cbse10.html` | CBSE Class X toppers *(coming soon)* |

## Data Source

HSC data is fetched live from Google Sheets (published as CSV). The page auto-refreshes every 15 minutes.

## Hosting

Deployed via GitHub Pages. Custom domain via DuckDNS with A records pointing to GitHub Pages IPs.
